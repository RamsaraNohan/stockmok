# F6 Responsive, Accessibility, and Visual QA Prompt

**TASK ROUTING:** Antigravity Gemini 3.6 Flash High for browser/a11y repair; Gemini 3.1 Pro High for difficult frozen-composition defects; Codex Sol high for regression/tests/contracts.
**WORKTREE/BRANCH:** frontend worktree / `feature/frontend`.

## Purpose

Close responsive, accessibility, visual-consistency and frontend-regression gaps across all 53 screens, 36 routes, 24 forms, 27 tables, 25 components and 44 states. Do not redesign.

## Required references

Read pack 02,05,06,09-16,20; all F0-F5 evidence; design freeze/checkpoint/manifest; UI 21-23,28-33; control-pack QA; all ten canonical design artifacts and all 105 current visual references.

## Requirements

Verify 390/768/1280/1920, under-1024 drawer, labelled mobile cards, no critical overflow, 12px text, 44px targets, focus/keyboard/dialog/table/tab/form/chart semantics, all async states, role/action visibility, console cleanliness and frozen visual hierarchy.

## Tests/evidence

Run frontend format/typecheck/lint/unit/component/service/build, Playwright UI subset, manual keyboard, accessibility automation, visual screenshot comparison, Lighthouse, bundle analysis and measured dashboard/product-list reads. Record actual results and defects.

## Allowed/forbidden scope

Frontend-owned code/tests/evidence only. No frozen design edits, aesthetic redesign, shared/C2/backend changes, production deployment or broad cleanup.

## Output/checkpoint

Resolve all P0/P1 defects, record remaining lower severity truthfully, commit `test(frontend): complete F6 responsive accessibility and visual QA`, then request independent frontend review/freeze. Author completion is not approval.

## Stop/quota

Stop for a required design change, cross-contract conflict or unsafe ownership expansion. Handoff per completed viewport/screen family with screenshots, defects and focused tests.
