## C1 seed mechanism exception

The owner approved an emulator-only Admin SDK bootstrap named `seed:bootstrap` / `replay:bootstrap`.
It proves data, schema, arithmetic, idempotent fixture construction, and reproducibility only. The canonical
`seed`, `replay`, `T-SEED-01a`, and `T-SEED-01b` names remain reserved for the later command-driven layer.

Before Claude Code implements C-13, C1-AUTH-007 must be propagated formally through DB-02, DB-06,
DB-08, DB-09, and the shared implementation contracts. C1 does not perform that protected-doc update.
