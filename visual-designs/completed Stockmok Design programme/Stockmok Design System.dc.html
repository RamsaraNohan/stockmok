Header contract
Always: mark, organisation monogram, untruncated organisation name, active-role badge, notification bell with unread count, user menu. Conditionally: workspace switcher. The organisation identity is not a link — it exists to prevent acting in the wrong workspace.
Sidebar contract
Sixteen canonical destinations in frozen order, filtered by assigned role. Network items (marked B) appear only when the connected-business release is enabled; direct access otherwise resolves to Not found, which is distinct from Permission denied.
Role never grants access
A requested role at sign-in is a preference only. Authorisation always comes from the assigned membership role. Unauthorised actions are hidden rather than disabled, except where hiding would make the screen incomprehensible.
Search is always local
Search exists only inside a FilterBar and only over the current list. There is no global search field, no command palette and no cross-tenant lookup.
Breadcrumb contract
One breadcrumb per detail screen, reflecting the real route hierarchy — never an invented parent. The current page is the last crumb and is not a link.
Switching workspace
Choosing another workspace revalidates membership and role before anything renders, and clears the previous tenant's cached data. You never see one organisation's figures under another's name.
