12aThe state grammar — twelve states, nine families, and where every cell is drawn
A state is a frame, not a paragraph
Every cell below is a drawn frame somewhere in Gates 5 to 12. This gate completes the cells that had only a rule behind them.
Four bands, one meaning each
Red refuses, amber warns and lets you continue, green confirms what happened, grey explains. No fifth colour, and no colour without a word.
Every refusal names the fix
Not one message in this gate says only that something failed. Each states what was refused, why, what is unchanged, and the next real step.
25 / 25 components
Banners, skeletons, empty states and validation are all specimens of components that already exist. Nothing on this gate is a twenty-sixth.

Why some cells are dashes
A stock operation is one indivisible write, so there is no half-recorded receipt to design. An invitation has nothing destructive on the accepting side, so it needs no confirmation. Saying so is stronger than leaving the cell blank.
The one partial failure that exists
The dashboard can render with one panel unavailable, because it reads several independent things. That state was drawn in Gate 6; the connections list has the same shape and is drawn here.
Failure never implies a write
Every failure message on this gate states the balance or record that is unchanged. A person who has just pressed a button in a stock room needs to know whether it happened, not what went wrong internally.

Sixty-two live cells, all drawn. The matrix is the deliverable as much as the frames are: it makes a missing state a visible hole rather than an oversight, and it names the ten cells that cannot occur so nobody later fills them with an invented screen.

THE RULEApplies everywhere
A skeleton, never a spinner
A centred spinner on a blank page tells the reader nothing except to wait. A skeleton tells them what is about to appear, how much of it there is, and roughly where to look — and it makes a slow read feel like progress rather than a stall.
Three things a skeleton must not do
1
Show a different number of rows than will arrive, which makes the page jump.
2
Fake a figure. No placeholder ever contains digits, because a glimpsed number is remembered.
3
Stay forever. After ten seconds it becomes the failure frame on 12d with a retry.

No placeholder in this system contains a digit. Skeletons carry geometry only — row heights, column widths, the timeline's marker gutter — so nothing that looks like a balance can be misread while the real figures are still on their way.

Two different sentences, always
An empty list says what a record is and offers to make one. A filtered list says what the filter excluded, names a figure that proves the data is still there, and offers to widen or clear it. Using one wording for both is the most common way an empty state lies.
One action, and it must be honest
Every frame here offers exactly one primary action the reader's role can actually perform. A Viewer sees the same sentence with no button rather than a button that will refuse them.

Eight frames, eight different sentences. Not one of them says No data or Nothing to show: each names the record type in the reader's language, states the figure that proves the workspace is intact, and offers the single next step its role permits.
